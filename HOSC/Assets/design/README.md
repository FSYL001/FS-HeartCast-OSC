# 设计源与预览

本目录保存新 Logo 的设计源文件与渲染预览，正式使用的矢量文件在上一级目录：

| 文件 | 用途 |
| --- | --- |
| `../AppIcon.svg` | 方形应用图标（矢量，含深色圆角底） |
| `../logo.svg` | 完整 Logo：图标 + `FS-HeartCast-OSC` 字标（文字已转曲） |
| `../AppIcon.png` | 1024×1024 透明底 PNG（README / 商店展示） |
| `../AppIcon.ico` | 16–256 px 多尺寸 Windows 图标 |
| `../Logo.xaml` | 应用内使用的 WPF 矢量图形（`AppLogo`） |

- `logo-v1.html`：第一版设计（旧，仅存档）
- `logo-v2.html`：第二版设计（当前 Logo 的来源，浏览器打开即可预览）
- `preview-v2.png`：由 `../logo.svg` 的绘制数据渲染的 1024×1024 预览图

> 说明：仓库中原先并没有 `preview-v2.png`，`preview-v2.png` 是由 `logo-v2.html` 的矢量绘制数据渲染得到的。
